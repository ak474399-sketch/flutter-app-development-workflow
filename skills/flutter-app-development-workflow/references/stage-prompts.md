# 各阶段引导模板

先查材料再问，复用已经确认的回答。以下问题是选择依据，不是要求每轮全部问完。先展示具体页面、表格或可运行产物；每轮聚焦当前阻断项，给推荐、理由和对范围／体验／工作量的影响。技术实现由 agent 判断；涉及产品行为、费用、数据处理的改变需要用户决定。阶段顺序是依赖关系，独立准备工作可先做；不适用阶段需记录原因与用户确认。

## 1 资料
自动查：已有 APK／报告的版本、哈希、可打开材料、现行决定及未观察分支。
必须用户决定：多个参考版本冲突时采用哪个；缺失材料取证还是按明确的新设计推进。
提问示例：“现有报告缺少恢复购买页面。推荐先保持待验证，补到证据后再定交互；如果你希望直接设计新恢复页，我会标为本产品新决定。采用哪种？”
默认产物：资料与来源清单、缺口。无 APK／报告时停在资料缺口，不发明竞品页面。

## 2 页面与交互
自动查：已观察路由、页面／弹窗／状态、入口与返回，整理参考行为和用户修改分栏。
必须用户决定：保留或改哪些流程；无法观察的分支是否纳入本轮。
提问示例：“参考的完整计划在首次使用必经，你之前要求移到设置。推荐按新决定整理首次引导，原完整计划保留设置入口；请验收流程图。”
默认产物：`assets/templates/page-interaction.json` 填写后的清单、流程边、用例。每个交互有触发／前置条件／结果／失败／数据影响；覆盖率以已确认范围为分母。

## 3 image 设计
自动查：允许改动的风格／颜色／布局／文案、内容密度、素材位置与指定参考。
必须用户决定：代表页方向验收；是否将该方向扩展至其余已定页面。
提问示例：“先提供首页和订阅页代表图，确认标题层级、内容密度和主视觉后再扩展。已有品牌决定会保留。”
默认产物：代表页、设计规则、提示词与素材映射。工具不可用则列真实缺口与可继续的 UI 框架，不登记图片完成。

## 4 Flutter UI
自动查：主／二级／详情覆盖、路由、状态、icon 占位、控件语义、输入／返回／滚动及尺寸。
必须用户决定：实际页面效果与差异；旧反馈冲突时哪个决定有效。
提问示例：“页面已能交互，主视觉还有两处占位，暂不满足本阶段完整验收。可先检查返回、输入和状态；素材替换后再验视觉。”
默认产物：可操作版本、素材账本、渲染／设备证据、UI 用例。设备不可用时只报告本地检查范围。

## 5 本地内容与功能
自动查：正文与目录、答案字段、完整度、存储范围、本地统计、保存／恢复用例。
必须用户决定：资料授权不明或业务指标含义不明；完整内容与内部样本范围。
提问示例：“目录有项目，正文却缺失。推荐列未完成内容，不把目录视为已交付。完整范围仍按你已确认的要求执行。”
默认产物：内容合同、完整度和本地业务闭环。固定内容生产与客户端运行时 AI 分开。

## 6 后端
自动查：实际需后端的功能、接口／认证／权限／幂等、配置位置和部署范围。
必须用户决定：没有已有决定的身份／数据保存规则、部署目标及涉及真实费用的操作。
提问示例：“测试可用正式服务，但测试包名和凭据仍独立。推荐先核测试身份、额度和写入范围，再做业务联调；已有明确授权不重问。”
默认产物：接口表、环境矩阵、真实客户端业务请求证据。没有配置不伪造联调通过；继续可独立完成的代码工作。

## 7 AI
自动查：模型／提示词／输入输出／额度现行决定，区分本地内容、演示状态和供应商结果。
必须用户决定：输出含义、未定的模型费用上限、发送哪些数据；模型替换影响产品时需说明。
提问示例：“结果字段没有可核对的数据来源。推荐显示缺失状态；新增真实分析服务需确认输入和数据处理范围。”
默认产物：提示词及模型配置模板、结构校验、真实输入输出及取消／重试证据。模型选择不继承旧产品；不声称恢复了原服务端 prompt。

## 8 SDK 与商业化
自动查：Firebase 三项、Meta 的独立配置、事件映射、采集同意；广告／订阅按已选分支读对应合同。
必须用户决定：商业化选择、商品／权益、页面广告时机与频率；两者同时选用时会员是否免广告、奖励与付费权益关系。
提问示例：“已选择订阅和广告。缓存机制有已定默认，但会员是否免广告尚无决定。这会影响广告开关和权益更新，需先明确。”
默认产物：基础接入与后台证据、所选模块真实链路。配置准备可早于第8阶段；页面预留可在第4阶段完成，实际权益与 SDK 验收不提前冒称完成。

## 9 整体验收
自动查：当前版本与哈希、未验用例、证据环境、缺陷和范围变更。
必须用户决定：实际产品验收、未验项是否接受有限范围；设备受阻时是否采用适合的替代范围。
提问示例：“逻辑测试通过，真实语音听感还未验。请按这份操作卡检查；本次只能验通过的范围，不能登记全量真机通过。”
默认产物：`assets/templates/acceptance.md`、报告与缺陷闭环。新修复重验受影响路径，不无限重跑无关测试。

## 10 上报与交付
自动查：实际截图、功能文案、品牌、当前目标商店规格、配置和签名位置、交付范围。
必须用户决定：代表上线图和最终素材验收；当前授权未包含的正式提交另确认。
提问示例：“已生成可编辑 banner、logo 和功能上线图，所有 UI 来自候选版本。先验代表图，再验完整导出清单与交付包。”
默认产物：素材源文件、源码、必要后端、配置模板、版本包／哈希、测试与缺口。正式构建、上传、审核、上线分别记录。

## 首次调用与续办输出
首次：十阶段概览 → 当前可复用材料 → 当前阶段与范围 → 已定选择／真正缺口 → 当前少量问题与推荐 → 下一产物和验收办法。
续办：读取现行决定／交接／project.json → 验证易变状态 → 当前有效验收 → 范围变化与需重验项 → 下一可执行工作。不要重新向用户询问已经可以从记录查出的资料。
