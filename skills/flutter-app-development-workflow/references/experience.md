# 经验来源与适用边界

整理日期：2026-10-09。本文件是历史经验摘要；用户本次确认的阶段和 SDK 默认选择属于新流程决定。案例不构成可复制全部代码、品牌或设备数据的授权。

## AI 英语
原始会话“获取逆向资料并生成英语 App”：先收集 ai-tutor 深度报告、课程内容、原 APK；后续明确要求真机采集页面与交互文档，调用 image 并参考 Figma 生成页面，技术 Flutter，先不做功能内容。

来源产物：项目 docs/DECISIONS.md 初期及0.3～0.9迭代；docs/reference-ui/页面与交互.md；Flutter页面映射历史；UI-POLISH-0.3.0.md；UI-VISUAL-0.6.0.md；SECONDARY-DETAIL-UI-0.8.1.md；MICRO-MOTION-0.8.2.md；testing/UI_INTERACTION_CASES.md。

实际迭代：发现大量 icon 占位、引导及缺省页缺失→补齐；语义图标、层次、间距、滑动、触感→复验；视觉过度→先新样稿获得确认再应用；二级／详情／微动效完善；用户明确先补 UI 用例再开发本地功能；随后内容、AI、语音、后端、下载与多语言分别推进。

内容经验：内容目录／题目字段／完整正文独立核对；本机建设的固定教材与运行时对话不同；完成报告明确内容缺口。课程数量、语言数量、下载网络策略、模型、奖励和广告频率均是案例决定，不作为默认值。

IAA 来源：ADS-TEST-20261007.md、ADS-FIREBASE-PRODUCTION-20261007.md、UI-COMMERCIAL.md、HANDOFF-0.15.1-20261008.md。已有原生广告接入、共享缓存、互斥／失败放行、布局边界、服务端验证代码与测试；正式填充、实际签名回调和到账未完整验收。最新0.15.1正式包保留广告SDK并关闭运行。不能把历史接入称为正式收入验证。

Firebase 来源：lib/production_firebase.dart、正式接入合同；Analytics／Crashlytics／Remote Config 已接代码，但后台事件、崩溃、远端值验收仍有缺口。原实现与广告耦合，本次新共享SDK解除该依赖。

## AI 扫脸 / LumaSignal
原始会话“逆向的干活”：先通过 APK 逆向历史分析 com.pulselio.android.com 页面；随后要求取得页面并重新生图，明确改变风格／颜色的范围。之后用户逐次要求补引导／订阅、替换插画、修正引导顺序、相机比例、等待动画、报告字段、真实数据和返回路径。

来源产物：vivasignal-demo/ui/ROUTE_MATRIX.md；docs/design/PULSELIO_FACE_SCAN_RUNTIME_AUDIT_2026-09-30.md；各版本 PRD；docs/prd/LUMASIGNAL_PRD_V1_21.md；测试与交接记录。

页面经验：相机预览不能被插画挡住／拉伸；采集、等待、报告不是一个状态；进入来源决定返回目的地；参考的具体采样技术与自有实现分别核对。用户后续指定美国中老年女性视角优化是特定改版指令，不能加入所有项目的前置人群定义。

报告经验：本地算法、真实供应商结果与缺失字段分开，缺测使用明确缺失状态；生成动画不证明结果已生成。

订阅经验：已有入口、订阅视觉、权益演示和本地模拟状态；Google Play Billing、实际购买和真实恢复未完成。本次在此基础上新实现了通用购买／恢复客户端、页面和验证调用；真实商店购买与本产品后端仍须新验，不倒填成旧项目成果。
