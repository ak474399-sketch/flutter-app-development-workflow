# 类别化开发经验与适用边界

本文件按 AI 订阅类与广告变现产品整理可复用经验。摘要为转述，不是源记录逐字稿；源项目名称、目录、品牌和专属业务不进入共享流程。历史结果不能继承为新产品通过。

## 通用页面与功能流程

从已有 APK／逆向报告、页面证据和真实用户修改出发，先整理页面、流程和交互，再输出代表设计图、可交互 Flutter UI；实际产物经用户验收后进入依赖它的功能阶段。

页面迭代需覆盖主入口图像占位、引导、缺省状态、二级／详情页、图标语义、层级、间距、返回、滑动及微动效。视觉反馈先用代表样稿对齐，再应用至已授权页面。具体颜色、形象和品牌不是通用默认。

本地内容与功能、后端交互、AI 服务分别实施和验收。内容目录不等于完整正文；固定内容建设和运行时调用分开；缺失或无来源的结果保持明确状态，不用动画或假数据填满。

## AI 订阅类产品

可复用付费入口、订阅页面布局、加载／购买／恢复／失败状态及权益生效后的返回体验。历史案例中页面和本地权益演示不代表真实 Billing 已完成。通用订阅 SDK 提供真实商店客户端适配、购买／恢复状态机、页面和 HTTPS 验证调用；各产品仍须独立准备商品、验证后端和权益规则。

订阅页面默认上方主视觉、下方权益／套餐／主按钮和法律链接；关闭按钮首次可见帧起2秒显示。购买或恢复经验证且权益生效后自动关闭一次。页面演示、商店回调、真实验证和权益到账分别记录。

## 广告变现产品

复用共享库存、并发上限、过期释放、展示互斥、失败放行、迟到回调处理与布局边界；通用广告 SDK 提供状态机和真实 Google Mobile Ads 适配器。广告入口、类型、单元和频率按产品确认，不复制旧产品配置。

已确认默认机制：每池 ready＋pending 最多2条，插页共享最多4条，55分钟过期，全局最多4个并发请求。只启用所选格式；激励 earned、服务端验证和权益到账分开。真实填充、收入与归因不由单元测试代验。

## 基础 SDK 与交付

Firebase Analytics／Crashlytics／Remote Config 和 Facebook App Events 为本流程默认必选模块；集成必选不等于自动获得采集同意。订阅、IAA 各自可选。客户端接入、后台接收与归因分验。

交付包含页面／流程／交互清单、image 页面设计和独立素材替换、banner、logo、真实 UI 上线图、源码、配置模板、版本包及哈希。只有明确要求才提交商店；构建、上传、审核和上线分别记录。

当前 SDK 是可复用客户端实现，不是已逐产品完成商业验证的通用收费系统。Android-first；iOS 原生 Meta 适配仍未实现。
