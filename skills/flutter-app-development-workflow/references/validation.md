# 首版验证与能力边界

执行环境：Flutter 3.41.9、Dart 3.11.5；Android debug 共同编译宿主。依赖版本由各包 pubspec.lock 固定，升级后重新验证。结果清单见仓库根 VALIDATION.json。

实际已执行：
- Python 流程／素材检查15项通过：阶段依赖、方案与验收区分、变更后的验收失效、真实文件哈希、越界路径、来源映射、占位图、必选模块、PNG CRC／尺寸及ZIP内容。
- 基础 SDK 7项通过：同意门槛、撤销、激活去重、参数白名单、失败重试、远端类型与前值、错误正文隔离、原生通道合同。
- IAA 8项通过：未选零初始化、容量／并发、关闭后迟到释放、过期、互斥／失效机会、唯一租约、超时保留物理槽位、插页总容量。
- 订阅11项通过：pending／取消／失败、重复回调、验证与商店确认重试、未知商品、恢复、离页、2秒边界、购买／恢复成功关闭、小屏／大字／RTL。
- 三模块共同 Android debug APK 编译成功；这验证原生依赖和 API 兼容，不表示真机启动／真实服务已验。
- 引导行为由本 agent 走查，详见 behavior-walkthrough.md；没有独立 agent 或其它模型实测。

明确未完成：真实 Firebase／Meta 配置和后台接收／归因；真实广告填充、SSV和收入；每产品订阅商品、真实验证后端、商店交易、续订／退款／撤销闭环；iOS 原生 Meta 适配、iOS编译和商店测试。调用者必须在本产品相应阶段完成，不能从首版SDK测试继承。

首版提供验证后端合同和客户端适配，不提供万能的商店／权益后端。新增登录、账户绑定、复杂优惠、订阅升级降级、平台特定恢复规则均按实际需求扩展，不能由 DemoGrant 或未经验证的 JSON 代替。
