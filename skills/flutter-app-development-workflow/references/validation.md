# 验证与能力边界

执行环境：Flutter 3.41.9、Dart 3.11.5；Android debug 共同编译宿主。依赖版本由各包 pubspec.lock 固定，升级后重新验证。结果清单见仓库根 VALIDATION.json。

2026-10-10 实际复验共50项自动检查通过：
- Python 流程／素材检查24项通过：原有15项，增加阶段完整性、合法ID、正整数版本、空白与字段类型、不可移除的前置依赖等9项回归检查。子用例不额外计数。
- 基础 SDK 7项通过：同意门槛、撤销、激活去重、参数白名单、失败重试、远端类型与前值、错误正文隔离、原生通道合同。
- IAA 8项通过：未选零初始化、容量／并发、关闭后迟到释放、过期、互斥／失效机会、唯一租约、超时保留物理槽位、插页总容量。
- 订阅11项通过：pending／取消／失败、重复回调、验证与商店确认重试、未知商品、恢复、离页、2秒边界、购买／恢复成功关闭、小屏／大字／RTL。
- 原先21个隔离阶段记录用例复验均符合预期，之前4个漏拦已拒绝；3个agent职责边界仍不能被脚本代判。
- 两个独立agent执行8个引导场景，其中A2出现阶段进入措辞歧义；修订后用第三个新agent复验，已区分执行授权、独立准备与阶段进入。输入、原始答复、审阅判断和限制见 [独立验证报告](evaluations/20261010/report.md)。不是跨模型研究或独立评分器评测。

历史验证：v0.1.0 的三模块共同 Android debug APK 编译成功，并从干净 Git 副本再次编译通过；这验证原生依赖和 API 兼容，不表示真机启动／真实服务已验。本轮仅修订流程检查器与引导文档，未改 SDK，未重建原生包。首版同agent走查保留在 behavior-walkthrough.md，不冒充本轮独立验证。
