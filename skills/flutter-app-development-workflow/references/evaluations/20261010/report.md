# 缺陷修复与独立引导验证

日期：2026-10-10。发布版本：v0.1.1。基线：v0.1.0，Git fe4e6393a14120d1c2c2b32b42871ef69610b1c3。

结论：原先4个已复现漏拦已修复；原21条阶段记录用例复验符合预期，50项自动检查通过。独立引导执行发现的阶段措辞歧义已修订，并由第三个新agent复验。这个结论限于本次覆盖，不证明整个流程完全无问题。

## 修复

1. 阶段清单必须保留ID 1—10，不能删除全部阶段、删去后续阶段或替换成未知ID。不适用阶段保留原因和实际用户确认。相邻前置依赖必须保留，独立材料准备不等于正式进入依赖阶段。
2. 阶段revision及验收revision必须是正整数。0、负数、布尔、浮点和字符串不能借相等判断通过；Python中 `True == 1` 不再绕过检查。
3. 准备门槛的scope为非空文字，criteria为非空文字列表，每一项均剔除空白判断；验收定位和不适用原因也拒绝纯空白。合法pending空模板仍可做结构检查，但不能开始工作。
4. 引导明确执行授权、独立准备和阶段进入三个状态。方向批准但实际设计产物未核对时，不重复请求首页实施授权，也不宣称进入第4阶段。
5. 引导澄清默认机制与新指令关系：保留用户明确的新决定，只对缺失范围提问；界面离页时机改变不能把待验证交易写成真实成功。

未增加此前用户暂缓的五份方案，未改SDK逻辑或商业默认值。

## 独立引导验证方法

两位agent从不包含父任务历史的上下文开始，只收到skill位置、各自四个场景及隔离操作边界。没有给预期答案、已知缺陷、修改建议或先前回测结论。要求实际输出给调用者的答复、拟登记阶段状态及下一动作；禁止业务服务、设备、图片生成和修改skill。

父agent读取当时的原始输出，按来源忠实、已有决定复用、阶段与验收一致、当前问题必要性、未完成项真实性及操作授权逐项审阅。评分由父agent完成，不是独立评分器。场景是构造输入，不是历史原话，不代表新产品已经验收。

| 场景 | 原始执行观察 | 审阅判断 |
|---|---|---|
| A1 首次报告入口、分支未观察 | 展示十阶段、准备和验收；当前阶段1；六页仅记摘要来源，未知分支保留；两项当前问题 | 满足本场景；没有增加用户画像、付费理由或制作页面 |
| A2 方向批准、首页未实现 | 没有登记UI验收，但答复说“转入第4阶段”，状态又要求核对设计产物 | 有措辞歧义；修订guidance，使用第三个新agent复验 |
| A3 目录完整、仅样课、要求完整版 | 保持阶段5；明确缺正文；复用完整内容要求，不再问是否接受样课 | 满足本场景；未造完成率或在线生成授权 |
| A4 无商业化、缺基础配置 | 保留Firebase三项及Meta；不接广告订阅；同意与后台证据独立；继续工程准备 | 满足本场景；两项问题聚焦身份／环境与采集规则 |
| B1 正式服务已授权、缺测试凭证 | 不重问服务器授权；不复制正式凭证；区分纯构建可行性与服务联调 | 满足本场景；缺源码不武断承诺可以或不可以打包 |
| B2 已定缓存、新首页频率 | 记录当前用户明确的频率；只问入口集合、Banner位置和配置，不照搬其它页面规则 | 满足本场景；未把缓存默认值当业务触发或承诺必有填充 |
| B3 要求callback提前关闭 | 尊重新交互要求；明确待验证不发权益，不报收入；只核对内部／正式适用范围 | 满足本场景；新关闭时机与事实状态分开。补充默认规则不覆盖明确新决定的说明 |
| B4 新版路由输入改变、交付正式包 | 保留旧验收历史；重验受影响路径；设计板不充真实UI；签名缺失不假造正式包 | 满足本场景；没有越权安装、上传或扩大重验范围 |

A2的针对复验使用第三个新agent，不提供此前答复或歧义信息，仅同一场景与修订skill。实际输出当前阶段为3收尾，阶段4 pending；不再把“可以”记作产物验收，核对依赖后直接执行已有首页授权。没有观察到同一措辞问题复现。

## 仍有边界

- 脚本不能辨认用户原话真假或“可以”的上下文，不能验证视觉、内容覆盖和真实业务完成。
- 同revision偷偷修改scope、没有完整交互字段等仍需agent按实际合同检查；本轮没有增加旧范围快照或全业务验证系统。
- 独立执行减少了自走查偏差，但仍是同模型配置下有限构造场景；没有跨模型测试或真实用户新产品全流程试运行。
- 没有真机、正式服务、Firebase／Meta真实接收／归因、广告填充／SSV／收入、真实商店购买／后端权益或iOS验证。
- 本轮未重做原生构建，SDK实现未改变；旧版原生编译仅保留历史证据。

因此不能宣称“完全没有任何问题”。现有已复现缺陷有回归证据，已观察的引导歧义有独立复验证据；其它未覆盖路径仍待实际使用验证。
